# FEATURE-001 - Authentication

**Owner:** Student 1 · **Priority:** High

Build register, login, logout, JWT, current-user, protected routes and customer/admin roles across PostgreSQL, Prisma, NestJS, API, client and admin. Acceptance: duplicate emails and invalid credentials are rejected; passwords are hashed; `/auth/me` requires JWT; admin-only routes reject customers; client logout clears auth and cached API state.
